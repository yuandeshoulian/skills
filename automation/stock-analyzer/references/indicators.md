# 技术指标参考手册

本文档介绍股票分析中常用的技术指标，包括其计算原理、使用方法和分析要点。

---

## 一、移动平均线 (MA)

### 概述
移动平均线是将一段时间内的股价加以平均，连接成线，用于观察股价趋势。

### 常用周期
- **MA5**：5日均线，反映短期趋势
- **MA10**：10日均线，短期趋势确认
- **MA20**：20日均线，月线，中期趋势参考
- **MA60**：60日均线，季线，中长期趋势参考

### 分析要点

**均线排列**：
- **多头排列**：MA5 > MA10 > MA20 > MA60，表示上涨趋势
- **空头排列**：MA5 < MA10 < MA20 < MA60，表示下跌趋势
- **均线交织**：无明确趋势，处于震荡状态

**支撑与压力**：
- 上升趋势中，均线起到支撑作用
- 下降趋势中，均线起到压力作用

**金叉与死叉**：
- **金叉**：短期均线上穿长期均线，买入信号
- **死叉**：短期均线下穿长期均线，卖出信号

---

## 二、MACD指标

### 概述
MACD（Moving Average Convergence Divergence）异同移动平均线，是趋势类指标。

### 组成部分
- **DIF**（快线）：12日EMA - 26日EMA
- **DEA**（慢线）：DIF的9日EMA
- **MACD柱**：(DIF - DEA) × 2

### 分析要点

**金叉与死叉**：
- DIF上穿DEA为金叉，买入信号
- DIF下穿DEA为死叉，卖出信号
- 金叉出现在0轴上方更有效

**红绿柱**：
- 红柱（正值）：DIF > DEA，多头力量
- 绿柱（负值）：DIF < DEA，空头力量
- 红柱变长表示多头增强，绿柱变长表示空头增强

**背离**：
- **顶背离**：股价创新高，MACD不创新高，见顶信号
- **底背离**：股价创新低，MACD不创新低，见底信号

---

## 三、KDJ指标

### 概述
KDJ（Stochastic Oscillator）随机指标，是震荡类指标，用于判断超买超卖。

### 组成部分
- **K值**：快线
- **D值**：慢线（K的平滑）
- **J值**：3K - 2D，敏感度最高

### 数值范围
- K、D值范围：0-100
- J值可能超过0-100范围

### 分析要点

**超买超卖**：
- K > 80、D > 80：超买区域，可能回调
- K < 20、D < 20：超卖区域，可能反弹
- J > 100：极度超买
- J < 0：极度超卖

**交叉信号**：
- K线上穿D线，金叉，买入信号
- K线下穿D线，死叉，卖出信号

**背离**：
- 股价与KDJ背离时，注意趋势反转

---

## 四、RSI指标

### 概述
RSI（Relative Strength Index）相对强弱指数，衡量买卖力量对比。

### 计算周期
常用RSI(14)，即14日相对强弱指数。

### 数值范围
0-100之间

### 分析要点

**超买超卖**：
- RSI > 70：超买区域，可能回调
- RSI < 30：超卖区域，可能反弹
- RSI > 80：极度超买
- RSI < 20：极度超卖

**中轴线**：
- RSI > 50：多头占优
- RSI < 50：空头占优

**背离**：
- 顶背离和底背离信号较可靠

---

## 五、布林带 (BOLL)

### 概述
布林带由三条轨道线组成，反映股价波动范围。

### 组成部分
- **上轨**：中轨 + 2倍标准差
- **中轨**：20日移动平均线
- **下轨**：中轨 - 2倍标准差

### 分析要点

**轨道宽度**：
- 布林带收口：波动率降低，可能面临方向选择
- 布林带开口：波动率增大，趋势可能加强

**价格位置**：
- 股价触及上轨：可能回调
- 股价触及下轨：可能反弹
- 股价在中轨附近：方向不明确

**突破信号**：
- 股价突破上轨：强势上涨
- 股价跌破下轨：强势下跌

---

## 六、成交量指标

### 概述
成交量是技术分析的重要辅助指标，验证价格走势的有效性。

### 分析要点

**量价关系**：
- **量增价涨**：健康上涨，趋势可持续
- **量增价跌**：抛压较重，可能继续下跌
- **量缩价涨**：上涨动力不足，注意风险
- **量缩价跌**：卖盘减少，可能见底

**换手率**：
- 换手率 > 10%：活跃
- 换手率 > 20%：高度活跃
- 换手率 < 1%：不活跃

---

## 七、综合分析框架

### 趋势判断优先级
1. 首先看均线系统（MA5/10/20/60排列）
2. 确认MACD趋势方向
3. 用KDJ/RSI判断当前位置
4. 布林带辅助判断波动区间

### 信号确认
- 多个指标同时发出相同信号，可靠性更高
- 单一指标信号需谨慎对待

### 风险提示
- 技术分析不能100%预测未来
- 需结合基本面和消息面综合判断
- 注意市场整体环境影响

---

## 八、指标组合使用建议

### 买入信号组合
1. 均线多头排列
2. MACD金叉或红柱放大
3. KDJ/RSI从超卖区域向上
4. 成交量配合放大

### 卖出信号组合
1. 均线空头排列
2. MACD死叉或绿柱放大
3. KDJ/RSI进入超买区域
4. 成交量异常放大或萎缩

### 震荡行情特征
1. 均线交织
2. MACD在0轴附近波动
3. KDJ/RSI在中间区域波动
4. 布林带收口

## 九、市值分析

### 概述
市值是股票分析的重要维度，不同市值规模的股票有不同的特性和分析方法。

### 市值分类

| 分类 | 市值范围 | 特点 |
|------|----------|------|
| 小市值 | < 50亿 | 波动大，易受主力操控 |
| 中小市值 | 50-200亿 | 波动较大，需关注资金动向 |
| 中等市值 | 200-500亿 | 相对均衡 |
| 大市值 | 500-2000亿 | 走势稳定 |
| 超大盘 | > 2000亿 | 受宏观经济影响大 |

### 小市值股票特点

**风险特征**：
- 容易被主力资金操控
- 技术指标可能失真
- 拉升出货风险高
- 流动性风险

**分析方法**：
- 降低技术指标权重
- 重点监控资金流向
- 关注主力动向
- 散户情绪作为反向指标
- 设置更严格的止损

### 大市值股票特点

**特征**：
- 走势相对稳定
- 技术指标有效性高
- 主要受基本面驱动
- 受行业和宏观经济影响

**分析方法**：
- 技术分析更可靠
- 重点关注基本面
- 关注行业趋势
- 机构研报参考价值高

## 十、散户情绪分析

### 概述
散户情绪是重要的市场反向指标。当散户情绪过于一致时，往往预示着行情的反转。

### 数据来源
- 股吧帖子（东方财富）
- 投资者投票数据
- 社交媒体讨论

### 情绪指标

**看多/看空比例**：
- 看多比例 > 70%：极度乐观，警惕回调
- 看空比例 > 70%：极度悲观，可能是底部
- 比例接近50%：分歧较大，方向不明

**讨论热度**：
- 热度极高：关注度达到顶峰，注意风险
- 热度低：关注度低，可能被忽视

### 反向指标原理

**极端情绪反向信号**：
1. **极度看多**（看多>70%）：散户大量进场时，主力可能出货
2. **极度看空**（看空>70%）：散户恐慌抛售时，可能是底部

**注意事项**：
- 情绪指标不是精确的买卖信号
- 需结合其他指标综合判断
- 小市值股票的反向指标效应更强
- 情绪数据存在噪音，不要过度依赖

### 使用建议

| 情绪状态 | 建议 |
|----------|------|
| 极度看多（>70%） | 谨慎，考虑减仓 |
| 偏看多（50-70%） | 保持警惕 |
| 分歧较大（40-60%） | 观望 |
| 偏看空（30-50%） | 关注机会 |
| 极度看空（<30%） | 可能是买入机会 |

## 十一、资金流向分析

### 概述
资金流向反映主力和散户的买卖行为，是判断短期走势的重要参考。

### 指标说明

**主力资金**：
- 大单交易（通常>50万）
- 代表机构和大户行为
- 对股价影响较大

**散户资金**：
- 小单交易
- 代表散户行为
- 通常与主力反向

### 分析要点

**主力资金趋势**：
- 持续流入（连续3天以上）：看多信号
- 持续流出：看空信号
- 反复震荡：方向不明

**主力vs散户**：
- 主力流入 + 散户流出：健康上涨
- 主力流出 + 散户流入：出货风险
- 双方同向：趋势确认

### 注意事项

1. 资金流向数据有滞后性
2. 主力可能分批操作
3. 小市值股票资金流向更敏感
4. 需结合成交量一起分析

---

## 十二、历史规律分析

### 概述
通过分析历史数据，挖掘股价运行的统计规律。

### 统计指标

**涨跌统计**：
- 上涨天数占比
- 连续上涨/下跌天数
- 最大连续涨跌幅

**波动分析**：
- 平均涨跌幅
- 波动率（标准差）
- 最大单日涨跌幅

**位置分析**：
- 当前价格在历史区间的位置
- 距离近期高点的距离
- 距离近期低点的距离

### 支撑压力位

**计算方法**：
- 近30日/60日最高价
- 近30日/60日最低价
- 密集成交区

**使用方法**：
- 接近压力位：注意风险
- 接近支撑位：关注机会
- 突破压力位：看多信号
- 跌破支撑位：看空信号

---

## 十三、不同市值股票的分析策略

### 小市值股票（<50亿）

**重点关注**：
1. 资金流向（权重40%）
2. 散户情绪反向指标（权重30%）
3. 消息面（权重20%）
4. 技术指标（权重10%）

**风险控制**：
- 严格止损
- 避免追高
- 警惕拉升出货
- 关注主力动向

### 中等市值股票（50-500亿）

**重点关注**：
1. 技术指标（权重30%）
2. 基本面（权重25%）
3. 资金流向（权重20%）
4. 消息面（权重15%）
5. 散户情绪（权重10%）

### 大市值股票（>500亿）

**重点关注**：
1. 基本面（权重35%）
2. 行业趋势（权重25%）
3. 技术指标（权重20%）
4. 资金流向（权重10%）
5. 宏观环境（权重10%）

**特点**：
- 技术指标有效性高
- 散户情绪影响小
- 更适合中长期投资
