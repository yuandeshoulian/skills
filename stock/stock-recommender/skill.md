# 股票智能推荐 Skill

## 概述

此Skill用于智能推荐A股优质股票。通过多维度筛选条件(技术面、基本面、资金面、市场面)，对全市场或指定板块的股票进行评分排序，筛选出最具投资价值的标的，并生成详细的推荐报告。

**核心功能**：
- 多维度智能评分（技术、基本面、资金、市场热度）
- 灵活的筛选条件设置（市值、行业、涨跌幅等）
- 风险等级分类与提示
- 自动生成推荐报告

## 触发条件

当用户请求包含以下内容时触发：
- 推荐股票、选股、找股票
- 寻找投资机会
- 使用 `/stock-recommender` 命令

## 使用方式

```bash
# 基础推荐（使用默认条件）
/stock-recommender

# 指定推荐数量
/stock-recommender --limit 10

# 指定市值范围（单位：亿）
/stock-recommender --min-cap 50 --max-cap 500

# 指定行业
/stock-recommender --industry 电子 半导体

# 综合示例
/stock-recommender --limit 20 --min-cap 100 --industry 新能源 医药
```

或直接说：`帮我推荐几只优质股票` 或 `找一些中小市值的科技股`

## 工作流程

### 步骤1：确认筛选条件

1. 接收用户输入的筛选条件（市值、行业、涨跌幅等）
2. 如未指定，使用默认条件：
   - 推荐数量：10只
   - 市值范围：不限
   - 行业：不限
   - 涨跌幅范围：不限

### 步骤2：获取股票池

执行推荐脚本获取候选股票池和评分结果。

```bash
cd {PROJECT_DIR} && python {SKILL_DIR}/scripts/recommend_stocks.py \
  --limit 10 \
  --min-cap 50 \
  --max-cap 500 \
  --industry 电子 半导体 \
  -o recommendation_data.json
```

**脚本参数说明**：
- `--limit`: 推荐股票数量（默认10）
- `--min-cap`: 最小市值（亿）
- `--max-cap`: 最大市值（亿）
- `--industry`: 行业列表（可多个）
- `--exclude-st`: 排除ST股票（默认True）
- `--min-score`: 最低综合评分（默认60）
- `-o`: 输出文件路径

### 步骤3：评分维度说明

推荐算法基于以下维度进行评分（总分100分）：

#### 技术面评分（30分）
- 均线系统（10分）：多头排列加分，空头排列减分
- MACD信号（5分）：金叉加分，死叉减分
- KDJ/RSI（5分）：超卖区域加分，超买区域减分
- 趋势强度（5分）：上涨趋势加分
- K线形态（5分）：看涨形态加分

#### 基本面评分（25分）
- 估值水平（8分）：PE、PB处于合理区间加分
- 盈利能力（8分）：ROE、毛利率高加分
- 财务健康（5分）：资产负债率低、流动比率高加分
- 业绩增长（4分）：业绩预告、同比增长加分

#### 资金面评分（25分）
- 主力净流入（15分）：持续净流入加分
- 资金流入趋势（5分）：近5日资金流入趋势
- 换手率（5分）：适度换手加分

#### 市场面评分（20分）
- 行业表现（8分）：所属行业涨幅靠前加分
- 概念热度（7分）：属于热门概念加分
- 散户情绪（5分）：情绪适中加分（极端情绪反向扣分）

### 步骤4：风险等级分类

根据市值规模和波动率，将股票分为不同风险等级：

| 风险等级 | 市值范围 | 波动率 | 说明 |
|---------|---------|--------|------|
| 低风险 | >500亿 | <3% | 大盘蓝筹股，走势稳健 |
| 中低风险 | 200-500亿 | 3-5% | 中等市值，相对稳定 |
| 中等风险 | 50-200亿 | 5-8% | 中小市值，有一定波动 |
| 中高风险 | 20-50亿 | 8-12% | 小市值，波动较大 |
| 高风险 | <20亿 | >12% | 超小市值，高度投机 |

### 步骤5：生成推荐报告

生成Markdown格式的推荐报告，保存到项目的 `reports/` 目录。

## 脚本说明

**脚本位置**：`{SKILL_DIR}/scripts/`

### recommend_stocks.py

股票推荐主脚本，输出JSON格式：
- 候选股票池（全市场或符合条件的股票）
- 多维度评分（技术面、基本面、资金面、市场面）
- 综合评分排序
- 风险等级分类
- 推荐理由生成

**评分算法**：
1. 获取全市场或指定范围的股票数据
2. 应用筛选条件过滤
3. 计算各维度得分
4. 加权求和得到综合评分
5. 排序并返回Top N

**数据源**：
- 实时行情：腾讯财经API（主）、同花顺（备）
- 技术指标：akshare
- 财务数据：akshare
- 资金流向：akshare
- 行业板块：akshare

## 注意事项

1. **数据质量**：
   - 推荐结果依赖数据准确性
   - 交易日数据更准确
   - 遇到API限流会自动重试

2. **评分客观性**：
   - 评分模型基于量化指标
   - 不考虑重大消息面因素
   - 建议结合人工判断

3. **风险控制**：
   - 小市值股票风险高，谨慎推荐
   - ST股票默认排除
   - 建议设置止损位

4. **市场环境**：
   - 熊市中评分标准会更严格
   - 牛市中适当放宽条件
   - 震荡市重点关注资金面

5. **更新频率**：
   - 建议盘中每小时更新一次
   - 收盘后生成完整报告
   - 非交易日数据为上一交易日

6. **免责声明**：
   - 推荐仅供参考，不构成投资建议
   - 股市有风险，投资需谨慎
   - 建议分散投资，控制仓位

## 高级用法

### 自定义评分权重

可以在脚本中调整各维度的权重：

```python
# 默认权重
WEIGHTS = {
    "technical": 0.30,    # 技术面30%
    "fundamental": 0.25,  # 基本面25%
    "capital": 0.25,      # 资金面25%
    "market": 0.20        # 市场面20%
}
```

### 组合策略

可以结合多个筛选条件创建组合策略：

```bash
# 价值投资策略（重基本面）
python recommend_stocks.py --strategy value --min-cap 100

# 成长投资策略（重业绩增长）
python recommend_stocks.py --strategy growth --industry 科技

# 动量交易策略（重技术面和资金）
python recommend_stocks.py --strategy momentum --min-score 70
```
