# 股票智能分析 Skill

## 概述

此Skill用于分析A股股票走势。输入一组股票代码，自动采集相关数据（行情、技术指标、财务、资金流向、业绩数据）和资讯（新闻、公告、研报、散户情绪），利用大模型进行综合分析，预测下一个交易日的走势，并生成Markdown格式的分析报告。

**增强功能**：
- 市值规模识别与小市值风险提示
- 散户情绪采集与分析（股吧数据）
- 历史数据扩大至120日，挖掘历史规律
- 业绩数据采集（业绩预告、业绩快报、财报）

## 触发条件

当用户请求包含以下内容时触发：
- 分析股票走势、预测股票趋势
- 输入股票代码进行分析
- 使用 `/stock-analyzer` 命令

## 使用方式

```
/stock-analyzer 600519 000858 300750
```

或直接说：`分析一下茅台和平安银行的走势`

## 工作流程

### 步骤1：确认股票代码

1. 接收用户输入的股票代码列表
2. 如输入的是股票名称（如"茅台"），需先查询对应代码
3. 确认最终要分析的股票列表

### 步骤2：采集数据

依次执行以下脚本采集数据。**注意**：脚本路径使用 Skill 目录，输出文件使用项目目录。

**2.1 采集股票数据**（行情、技术指标、财务、资金流向、业绩）

```bash
cd {PROJECT_DIR} && python {SKILL_DIR}/scripts/fetch_stock_data.py <股票代码1> <股票代码2> ... -o stock_data.json
```

**2.2 采集资讯数据**（新闻、公告、研报、市场概况、散户情绪）

```bash
cd {PROJECT_DIR} && python {SKILL_DIR}/scripts/fetch_news.py <股票代码1> <股票代码2> ... -o news_data.json
```

### 步骤3：数据分析

基于采集的数据，结合 `references/indicators.md` 中的技术指标参考，进行以下分析：

#### 技术面分析
- 趋势判断（多头/空头/震荡）
- 均线系统分析（MA5/10/20/60/120排列情况）
- MACD信号（金叉/死叉/红绿柱）
- KDJ和RSI超买超卖判断
- 布林带位置
- 成交量配合情况
- K线形态识别（十字星、锤子线、大阳线等）

#### 历史规律分析
- 近30日/60日涨跌统计
- 涨跌幅分布（最大涨跌幅、平均涨跌幅、波动率）
- 支撑位与压力位分析
- 成交量变化趋势

#### 基本面分析
- 估值水平（PE/PB）
- 盈利能力（ROE、毛利率、净利率）
- 财务健康度（资产负债率、流动比率）
- 业绩预告/快报分析

#### 资金面分析
- 主力资金净流入/流出
- 主力资金趋势（持续流入/流出/震荡）
- 散户资金动向

#### 消息面分析
- 公司公告要点（筛选重要公告）
- 相关新闻及情绪倾向
- 研报评级汇总及综合评级
- 所属行业/概念表现

#### 市值风险分析（重要！）
- 市值规模分类（小市值/中小市值/中等市值/大市值/超大盘）
- 小市值股票风险提示
- 根据市值调整分析权重

#### 散户情绪分析
- 股吧帖子情绪统计（看多/看空比例）
- 讨论热度分析
- **反向指标警告**：当散户情绪过于一致时（如极度看多），往往与实际走势相反

### 步骤4：综合判断逻辑

根据市值规模采用不同的分析策略：

**小市值股票（<50亿）**：
- 技术指标权重降低
- 重点关注资金流向和主力动向
- 关注散户情绪作为反向指标
- 提示操控风险

**中等市值股票（50-500亿）**：
- 技术面和基本面均衡分析
- 资金流向作为重要参考
- 散户情绪有一定参考价值

**大市值股票（>500亿）**：
- 技术指标有效性较高
- 基本面和行业趋势更重要
- 散户情绪影响较小

### 步骤5：生成报告

生成Markdown格式的分析报告，保存到项目的 `reports/` 目录。

**路径规范**：
- 报告目录：`{PROJECT_DIR}/reports/`
- 如目录不存在，需先创建：`mkdir -p {PROJECT_DIR}/reports`
- 文件名格式：`股票分析报告_YYYYMMDD_HHMMSS.md`

**重要**：报告必须保存在项目目录下，而不是 Skill 目录下。即使 Skill 部署在全局目录，物料也应跟随项目。

**报告结构**：

```markdown
# 股票智能分析报告

**分析时间**：YYYY-MM-DD HH:MM:SS
**下一个交易日**：YYYY-MM-DD 星期X（根据当前日期推算，周一至周五为交易日，如遇节假日顺延）
**分析股票**：股票代码列表

**重要：计算下一个交易日时必须**：
1. 使用Python计算，**必须用英文输出**避免编码问题
2. weekday()返回值：0=Monday(周一), 1=Tuesday(周二), 2=Wednesday(周三), 3=Thursday(周四), 4=Friday(周五), 5=Saturday(周六), 6=Sunday(周日)
3. 如果下一个交易日是周六(5)，则跳到下周一（+3天，从今天算）
4. 如果下一个交易日是周日(6)，则跳到周一（+2天，从今天算）
5. 示例代码：
   ```python
   from datetime import datetime, timedelta
   today = datetime.now()
   next_day = today + timedelta(days=1)
   weekday = next_day.weekday()  # 0=Monday, 4=Friday, 5=Saturday, 6=Sunday

   # 英文星期名（避免编码问题）
   weekday_en = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday', 'Sunday']
   weekday_cn = ['周一', '周二', '周三', '周四', '周五', '周六', '周日']

   if weekday == 5:  # Saturday
       next_trading_day = today + timedelta(days=3)  # 跳到周一
   elif weekday == 6:  # Sunday
       next_trading_day = today + timedelta(days=2)  # 跳到周一
   else:
       next_trading_day = next_day

   # 输出时用中文
   print(f"Next trading day: {next_trading_day.strftime('%Y-%m-%d')} {weekday_cn[next_trading_day.weekday()]}")
   ```

## 注意事项

1. 数据采集需要网络连接
2. 交易日数据更准确，非交易日可能获取到的是最后一个交易日数据
3. 预测仅供参考，不构成投资建议
4. 如遇API限流，适当等待后重试
5. **小市值股票风险**：技术指标可能失效，需结合资金流向和消息面综合判断
6. **散户情绪反向指标**：当散户情绪过于一致时，往往与实际走势相反
7. 股吧数据存在较大噪音，仅供参考
8. **数据源故障**：东方财富API偶尔会出现服务异常，导致大盘数据、行业板块数据获取失败。脚本已添加重试机制（3次重试，每次间隔3秒），如仍失败则跳过该部分数据，不影响个股分析
