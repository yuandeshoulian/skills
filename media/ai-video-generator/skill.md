# AI 视频生成器技能

## 核心工作流程

1. **角色设计** → 根据剧本生成角色形象图（文生图）
2. **场景生成** → 根据分镜脚本生成场景图片（文生图）
3. **关键帧绘制** → 根据角色+场景+分镜生成关键帧（图生图）
4. **视频生成** → 根据关键帧+分镜生成视频片段（图生视频）
5. **视频合成** → 拼接视频片段，添加音效和配音
6. **格式输出** → 生成最终视频，保存到指定目录

**重要说明**：
- 本技能会**自动完成**所有步骤
- ✅ **支持两套完整 API**：
  - **火山引擎/字节跳动**：文生图、参考生图、图生视频（Seaweed 2.0，12秒，带音频配音）
  - **阿里云**：文生图、参考生图、图生视频（VideoComposer，10秒）
- **可配置模型和时长**：支持未来更好的模型，时长限制可突破
- 自动管理生成的资产（角色图、场景图、关键帧、视频）
- 生成的视频保存到：`output/ai-video/[剧名]/`
- 可配合 `short-drama` 和 `storyboard-director` skill 使用

## 生成流程详解

### 步骤1：角色设计（文生图）

**输入**：剧本中的角色描述

**处理**：
1. 从剧本提取角色信息（姓名、年龄、外貌、性格）
2. 生成专业的角色设计提示词
3. 调用文生图 API 生成角色形象（多角度：正面、侧面、全身）
4. 保存角色形象到资产库

**输出**：
```
output/ai-video/[剧名]/characters/
├── 林宇-正面.png
├── 林宇-侧面.png
├── 林宇-全身.png
├── 张雪-正面.png
└── ...
```

**API 选择**：
- 火山引擎：MagicAnimate、DoubaoAI
- 阿里云：通义万相

**成本**：约 0.1-0.5 元/张

---

### 步骤2：场景生成（文生图）

**输入**：分镜脚本中的场景描述

**处理**：
1. 从分镜脚本提取场景信息（地点、时间、氛围、灯光）
2. 生成场景渲染提示词（竖屏 9:16 比例）
3. 调用文生图 API 生成场景背景
4. 保存场景图到资产库

**输出**：
```
output/ai-video/[剧名]/scenes/
├── 豪华酒店大堂-晚上.png
├── 酒店门外-晚上.png
├── 劳斯莱斯车内-晚上.png
└── ...
```

**API 选择**：
- 火山引擎：VisualGLM、DoubaoAI
- 阿里云：通义万相

**成本**：约 0.1-0.5 元/张

---

### 步骤3：关键帧绘制（图生图 + 文生图）

**输入**：
- 角色形象（步骤1生成）
- 场景图片（步骤2生成）
- 分镜脚本（镜头描述）

**处理**：
1. 根据分镜脚本的每个镜头生成关键帧
2. 使用角色图+场景图作为参考
3. 通过图生图保持角色和场景的一致性
4. 生成竖屏（9:16）关键帧
5. 保存关键帧到资产库

**输出**：
```
output/ai-video/[剧名]/keyframes/episode-001/
├── S1-1_豪华酒店大堂全景.png
├── S1-2_保安走向林宇.png
├── S1-3_保安阻拦林宇.png
├── S1-4_林宇淡定表情.png
└── ...
```

**API 选择**：
- 火山引擎：ControlNet + DoubaoAI
- 阿里云：通义万相图生图

**技术要点**：
- 使用 ControlNet 保持角色姿态和场景布局
- 使用 IP-Adapter 保持角色外貌一致性
- 使用参考图引导生成

**成本**：约 0.2-0.8 元/张

---

### 步骤4：视频生成（图生视频）

**输入**：
- 关键帧图片（步骤3生成）
- 分镜脚本（镜头描述、运镜、时长）

**处理**：
1. 根据分镜脚本的每个镜头生成视频片段
2. 使用关键帧作为视频第一帧
3. 根据运镜方式（推拉摇移跟）生成运动
4. 每个视频片段最长 12 秒（Seaweed 2.0 限制）
5. 保存视频片段到资产库

**输出**：
```
output/ai-video/[剧名]/videos/episode-001/
├── S1-1_豪华酒店大堂全景.mp4 (2秒)
├── S1-2_保安走向林宇.mp4 (2秒)
├── S1-3_保安阻拦林宇.mp4 (3秒)
├── S1-4_林宇淡定表情.mp4 (2秒)
└── ...
```

**API 选择**：
- **火山引擎 Seaweed 2.0**（推荐，效果最好）
  - 支持音效和配音生成
  - 最长 12 秒
  - 竖屏支持
- 阿里云通义视频生成

**技术要点**：
- 根据运镜方式设置运动参数
- 固定镜头：运动幅度小
- 推拉镜头：Z 轴运动
- 跟镜：跟随主体运动

**成本**：约 1-5 元/秒

---

### 步骤5：视频合成

**输入**：
- 视频片段（步骤4生成）
- 分镜脚本（镜头顺序、时长）
- 音效和音乐

**处理**：
1. 按照分镜脚本的镜头顺序拼接视频
2. 添加转场效果（可选）
3. 添加音效和背景音乐
4. 调整整体色调和节奏
5. 渲染最终视频

**输出**：
```
output/ai-video/[剧名]/final/
├── episode-001.mp4
├── episode-002.mp4
└── ...
```

**工具**：
- FFmpeg（视频拼接和处理）
- Python 脚本自动化

**成本**：几乎无成本（本地处理）

---

### 步骤6：音效和配音（可选）

**输入**：
- 最终视频
- 剧本对白
- 音效需求

**处理**：
1. 使用 TTS API 生成角色配音
2. 使用音效库或 AI 生成音效
3. 混音并与视频合成

**API 选择**：
- 火山引擎：火山 TTS
- 阿里云：阿里 TTS
- **Seaweed 2.0**：自动生成音效和配音（推荐）

**成本**：约 0.1-0.5 元/分钟

## 视频分段策略

### 为什么需要分段？

**Seaweed 2.0 限制**：单个视频最长 12 秒

**短剧需求**：每集 1-2 分钟（60-120 秒）

**解决方案**：分段生成，再拼接

### 分段方案

#### 方案1：按镜头分段（推荐）

**原理**：每个镜头生成一个视频片段

**优势**：
- 符合分镜脚本结构
- 每个镜头 1-5 秒，远小于 12 秒限制
- 灵活性高，可独立调整

**示例**：
```
第1集（90秒）= 45个镜头
每个镜头 2秒 = 45个视频片段
最后拼接成完整视频
```

#### 方案2：按场景分段

**原理**：每个场景生成一个视频片段

**限制**：
- 场景时长可能超过 12 秒
- 需要进一步细分

**适用**：场景较短（<12秒）的情况

## 成本估算

### 单集成本（1-2分钟短剧）

| 步骤 | 数量 | 单价 | 小计 |
|------|------|------|------|
| **角色设计** | 5角色×3角度 = 15张 | 0.3元/张 | 4.5元 |
| **场景生成** | 3场景 | 0.3元/张 | 0.9元 |
| **关键帧** | 45镜头 | 0.5元/张 | 22.5元 |
| **视频生成** | 90秒 ≈ 45镜头 | 2元/秒 | 180元 |
| **音效配音** | 1.5分钟 | 0.3元/分 | 0.5元 |
| **总计** | | | **208.4元/集** |

**说明**：
- 角色和场景可复用，后续集数成本降低
- 主要成本在视频生成（占 86%）
- Seaweed 2.0 效果最好但成本较高

### 成本优化建议

#### 1. 减少镜头数量
- 原始：45 镜头/集（平均 2 秒/镜头）
- 优化：30 镜头/集（平均 3 秒/镜头）
- 节省：15 镜头 × 2 元 = **30 元/集**

#### 2. 复用关键帧
- 固定镜头：直接复用关键帧作为静态画面
- 不需要生成视频
- 节省：10 个固定镜头 × 2 元 = **20 元/集**

#### 3. 使用低成本 API
- 火山引擎 Seaweed 1.0：1 元/秒
- 节省：90 秒 × 1 元 = **90 元/集**
- 但效果不如 2.0

**优化后成本**：约 **70-150 元/集**

## 质量控制

### 评分标准（总分 100）

#### 一、角色一致性（30 分）

| 评分项 | 分值 | 评分标准 |
|-------|-----|---------|
| **外貌一致** | 15分 | 角色在不同镜头外貌一致（12-15分）<br>基本一致但有差异（7-11分）<br>差异明显（0-6分） |
| **服装一致** | 10分 | 服装和造型一致（8-10分）<br>基本一致（5-7分）<br>不一致（0-4分） |
| **风格统一** | 5分 | 画风统一（4-5分）<br>基本统一（2-3分）<br>风格混乱（0-1分） |

#### 二、画面质量（30 分）

| 评分项 | 分值 | 评分标准 |
|-------|-----|---------|
| **画面清晰度** | 10分 | 高清无瑕疵（8-10分）<br>清晰但有小瑕疵（5-7分）<br>模糊或瑕疵多（0-4分） |
| **构图合理** | 10分 | 构图专业，竖屏适配好（8-10分）<br>构图尚可（5-7分）<br>构图差（0-4分） |
| **光影效果** | 10分 | 光影自然真实（8-10分）<br>基本合理（5-7分）<br>不自然（0-4分） |

#### 三、运动流畅度（20 分）

| 评分项 | 分值 | 评分标准 |
|-------|-----|---------|
| **运镜流畅** | 10分 | 运镜自然流畅（8-10分）<br>基本流畅（5-7分）<br>卡顿或不自然（0-4分） |
| **动作自然** | 10分 | 人物动作自然（8-10分）<br>基本自然（5-7分）<br>僵硬或扭曲（0-4分） |

#### 四、符合剧本（20 分）

| 评分项 | 分值 | 评分标准 |
|-------|-----|---------|
| **情节准确** | 10分 | 完全符合剧本情节（8-10分）<br>基本符合（5-7分）<br>偏离剧本（0-4分） |
| **氛围匹配** | 10分 | 氛围符合剧本要求（8-10分）<br>基本符合（5-7分）<br>不匹配（0-4分） |

### 判定标准

- **85-100分**：优秀，可直接使用 ✅
- **75-84分**：良好，小幅调整
- **60-74分**：及格，需要重新生成部分片段
- **<60分**：不及格，需要大幅调整或重新生成

## 常见问题

### Q1：如何保持角色在不同镜头的一致性？

**A**：
1. 使用 IP-Adapter 或 LoRA 固定角色外貌
2. 生成角色形象后，作为参考图使用
3. 每次生成关键帧时，传入角色参考图
4. 使用相同的角色提示词

### Q2：视频生成太慢怎么办？

**A**：
1. 并发生成多个视频片段
2. 使用更快的 API（但效果可能差）
3. 只生成关键镜头，其他用静态关键帧代替
4. 优化镜头数量

### Q3：成本太高怎么办？

**A**：
1. 减少镜头数量（从 45 个减到 30 个）
2. 固定镜头不生成视频，用静态关键帧
3. 使用低成本 API（Seaweed 1.0）
4. 角色和场景复用

### Q4：Seaweed 2.0 只能生成 12 秒，如何处理？

**A**：
1. 按镜头分段生成（每个镜头 1-5 秒）
2. 最后用 FFmpeg 拼接
3. 本技能自动处理分段和拼接

### Q5：生成的视频不符合剧本怎么办？

**A**：
1. 优化提示词，更详细地描述
2. 使用更多参考图引导
3. 重新生成不满意的片段
4. 调整关键帧，再重新生成视频
