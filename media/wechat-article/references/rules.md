## 🚫 去AI味核心规则（强制遵守）

### 禁止使用的设计元素

| 禁止项 | 说明 | 替代方案 |
|--------|------|----------|
| **Hero渐变区** | 超大渐变背景 + 大号emoji | 直接进入内容，用第一段吸引读者 |
| **蓝字渐变** | `linear-gradient` 做文字渐变 | 使用纯色 `#222/#333` |
| **紫蓝渐变背景** | #6a5acd → #1e90ff 等常见 AI 风格 | 使用自然单色渐变或纯色 |
| **过度组件化** | 每段都用框框起来 | 大部分内容自然流动，组件≤8个 |
| **固定配色模板** | 按类型套用配色 | 根据主题灵活选择 2-3 种主色调 |
| **固定Footer** | 每篇都有点赞在看分享 | 根据内容决定，自然结束也可 |

### 强制遵守的规则（2025 升级版）

| 规则 | 说明 |
|------|------|
| **无Hero区** | 直接进入内容，用第一段吸引读者 |
| **无蓝字渐变** | 使用纯色 `#222/#333` |
| **无紫蓝渐变** | 禁止 #6a5acd → #1e90ff 等常见 AI 风格渐变 |
| **emoji≤15个** | H2、H3 标题建议添加，但总量控制在 15 个以内 |
| **组件≤8个** | 允许表格+图表组合，但避免过度装饰 |
| **颜色丰富但协调** | 每篇文章选择 2-3 种主色调，根据主题自然搭配 |
| **无固定配色** | 不按文章类型套用固定配色模板 |
| **无固定Footer** | 可自然结束，不强制套路 |
| **无首行缩进** | 段落不使用 `text-indent`，现代网文风格 |

### 让文章像"人"写的（视觉丰富升级版）

1. **变化节奏** - 长短段落交替，表格和图表穿插其中，适当留白
2. **真实感** - 具体数据而非"很多"，真实案例而非笼统描述
3. **个性化** - 根据主题选择风格和配色，不套用模板
4. **视觉丰富但不过度** - 小标题加 emoji，有对比用表格，有数据用图表，但装饰为内容服务

## ⚠️ 微信公众号CSS限制（官方文档验证版）

**微信公众号对CSS有严格的白名单限制，所有样式必须用内联方式（inline style）写在元素的 `style=""` 属性中。**

### ❌ 完全不支持（会被过滤掉）

| 特性 | 说明 |
|------|------|
| `<style>` 标签 | 不支持任何样式块，所有CSS必须内联 |
| `<script>` 标签 | 不允许任何JavaScript |
| `::before` / `::after` | 伪元素完全不支持，用 `<span>` 替代 |
| `position: absolute/fixed/relative` | 会被微信删除，不能用定位布局 |
| `id` 属性 | 上传后会被删除，无法用于锚点跳转 |
| `display: grid` | 不支持网格布局 |
| `@media` 查询 | 不支持媒体查询，无法响应式 |
| `@keyframes` | 不支持CSS动画定义 |
| `float` | 不推荐，元素会脱离文档流导致布局问题 |
| `%` 百分比单位 | 在某些场景下失效（如 `transform: translateY(-100%)`） |

### ⚠️ 部分支持/有限制

| 特性 | 限制说明 |
|------|----------|
| `transform` | 历史不支持，现在部分支持，但iOS下 `transform-origin` 可能失效 |
| `linear-gradient` | 简单双色渐变可用，但**强烈建议优先使用纯色**以确保兼容性 |
| `flexbox` | 部分支持，但 `flex-wrap` 等属性不稳定 |

### ✅ 推荐使用（稳定支持）

| 特性 | 用法 |
|------|------|
| 内联样式 `style=""` | **所有样式必须写在这里** |
| `<table>` 布局 | 最可靠的布局方式，代替 flex/grid |
| 基础文本样式 | `font-size`, `color`, `font-weight`, `line-height` |
| 间距样式 | `margin`, `padding` |
| 边框样式 | `border`, `border-radius` |
| 阴影效果 | `box-shadow` |
| 对齐 | `text-align`, `vertical-align` |
| 显示类型 | `display: block`, `inline-block`, `table` |
| 单位 | 使用 `px` 或 `vw/vh` 代替百分比 |
| `z-index` | 配合 `display: flex` 在父容器上使用 |
| `pointer-events: none` | 禁用交互 |
| `opacity` | 透明度控制 |
| `text-decoration` | 下划线等 |

## 常见问题（微信兼容性）

### Q: 为什么文章上传到微信后段落有首行缩进？

**A:** 这是微信公众号编辑器的平台限制，无法通过 HTML/CSS 完全避免。

**原因**：
- 微信编辑器会忽略 `text-indent` 属性（包括 `!important`）
- 对所有段落类标签（`<p>`、`<div>`、`<section>` 等）自动应用默认格式
- 在导入 HTML 后会强制添加首行缩进样式

**解决方案（二选一）**：

**方案 1：手动清除格式（推荐）**
1. 打开草稿
2. 全选内容（Ctrl+A）
3. 点击工具栏的"清除格式"按钮
4. 或手动设置：格式 → 段落 → 首行缩进 → 设置为 0

**方案 2：接受这个样式**
- 首行缩进是传统中文排版的标准格式
- 对阅读体验影响不大
- 可以考虑保留这个样式

**注意**：这是微信公众号平台的限制，不是 HTML 生成的问题。所有第三方工具都会遇到这个问题。

### Q: 为什么网页预览正常，但微信中样式错乱？

**A:** 微信会过滤掉不支持的CSS属性。常见原因：
- 使用了 `<style>` 标签 → 改用内联样式 `style=""`
- 使用了 `::before/::after` 伪元素 → 改用 `<span>` 或直接写内容
- 使用了 `position: absolute` → 改用 `<table>` 布局
- 使用了 `display: grid` → 改用 `<table>` 或 flexbox

### Q: 为什么我的渐变背景在微信中没有显示？

**A:** 微信对渐变支持有限且不稳定。建议：
- **优先使用纯色** `background-color: #667eea`（最稳定）
- 如必须用渐变，仅使用简单双色渐变
- 发布前务必在多种设备上测试（iOS/Android、不同微信版本）

### Q: 为什么表格内容被截断了？

**A:** 微信表格需要特殊处理：
- 添加 `table-layout: fixed` 固定布局
- 所有单元格添加 `word-break: break-word`
- 用 `<td style="width:XX%">` 控制列宽

### Q: 为什么我的图片之间有白缝？

**A:** 图片默认是 inline 元素，有空隙。解决：
- 给图片添加 `display: block;`
- 或给父容器设置 `font-size: 0;`

### Q: 为什么百分比单位不起作用？

**A:** 微信对 `%` 支持有限。建议：
- 使用固定像素 `px`
- 使用视口单位 `vw/vh`
- 例如：不用 `width: 50%`，改用 `width: 50vw`

### Q: 手机端出现左右滑动？

**A:** 这是因为内容宽度超出容器导致。确保：
- 表格使用 `table-layout: fixed`
- 长文本添加 `word-break: break-word`
- 容器设置 `max-width: 677px` 和 `overflow: hidden`

### Q: 如何在微信中设置层级？

**A:** 由于 `position` 失效，层级设置方法：
```html
<!-- 父容器添加 display:flex -->
<div style="display:flex;">
  <!-- 子元素用 z-index -->
  <div style="z-index:10;">在上层</div>
  <div style="z-index:1;">在下层</div>
</div>
```

## 微信公众号标题格式限制

**微信公众号标题不支持以下内容：**
- ❌ Emoji 表情符号（如 🎯 🔥 💡 等）
- ❌ 特殊符号（如 【】『』「」等特殊书名号）
- ❌ 过长的标题（建议 64 字节以内，约 20-30 个汉字）

**推荐做法：**
- ✅ 使用纯文本标题
- ✅ 可以使用中文书名号《》
- ✅ 可以使用中文方括号【】
- ✅ 使用数字、问号、感叹号等基础标点
