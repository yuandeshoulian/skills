# 竖屏拍摄指南

本文档专门介绍竖屏（9:16）短视频的拍摄技巧和注意事项。

---

## 竖屏拍摄特点

### 竖屏 vs 横屏

| 维度 | 横屏（16:9）| 竖屏（9:16）|
|------|------------|------------|
| **画幅比例** | 宽大于高 | 高大于宽 |
| **适合内容** | 风景、多人、横向动作 | 人物、纵向构图 |
| **观看场景** | 电视、电脑 | 手机 |
| **用户习惯** | 需要横屏 | 符合持机习惯 |
| **空间利用** | 横向空间大 | 纵向空间大 |

### 竖屏的优势

#### 1. 更符合手机观看习惯
- 用户无需旋转手机
- 沉浸感更强
- 观看更舒适

#### 2. 更适合人物拍摄
- 可以从头到脚展现人物
- 面部特写更突出
- 人物在画面中占比更大

#### 3. 更容易突出主体
- 横向干扰少
- 视觉焦点集中
- 主体更清晰

### 竖屏的限制

#### 1. 横向空间小
- 不适合宽广场景
- 多人横向站立困难
- 横向运镜受限

#### 2. 群体场景困难
- 多人合照困难
- 横向对话场景受限
- 群体动作场景复杂

#### 3. 某些镜头语言受限
- 横向摇镜效果差
- 横向移镜空间小
- 宽广环境难以展现

## 竖屏构图

### 基本构图原则

#### 1. 三分法（Rule of Thirds）

**横屏三分法**：画面横竖各分三份，交叉点为视觉焦点

**竖屏三分法**：同样适用，但纵向空间更大

**应用**：
- 人物眼睛放在上三分之一线上
- 地平线放在上或下三分之一线上
- 主体放在左或右三分之一线上

**示例**：
```
┌─────────┐
│    ●    │ ← 人物眼睛（上1/3线）
│         │
│         │
│    ◆    │ ← 重要物品（中1/3线）
│         │
│         │
│         │ ← 地面（下1/3线）
└─────────┘
```

#### 2. 中心构图

**定义**：主体放在画面中心

**用途**：
- 正面特写
- 对称美感
- 强调主体

**示例**：
```
┌─────────┐
│         │
│    ●    │ ← 人物面部（中心）
│   /|\   │
│   / \   │
└─────────┘
```

**适用场景**：
- 人物正面特写
- 重要物品展示
- 对称场景

#### 3. 纵向构图

**定义**：利用竖屏的纵向空间

**类型**：

**A. 从下到上构图**
```
┌─────────┐
│   头部   │
│   身体   │
│   腿部   │
│   脚部   │
└─────────┘
```

**适用**：全身展示、走秀、展现身高

**B. 从上到下构图**
```
┌─────────┐
│  楼顶   │
│  楼层   │
│  楼层   │
│  地面   │
└─────────┘
```

**适用**：建筑、楼梯、瀑布等纵向场景

**C. 前后景构图**
```
┌─────────┐
│ 远景人物 │
│         │
│ 中景物品 │
│         │
│ 近景主角 │
└─────────┘
```

**适用**：制造空间感和层次感

## 竖屏景别选择

### 推荐景别分布

| 景别 | 占比 | 说明 |
|------|------|------|
| **中景** | 40-50% | 最常用，适合对话和动作 |
| **近景** | 30-40% | 突出表情，适合情绪表达 |
| **特写** | 10-20% | 强调细节，适合爽点时刻 |
| **全景** | 5-10% | 展现全身，谨慎使用 |
| **远景** | 0-5% | 横向空间不足，尽量少用 |

### 各景别在竖屏中的表现

#### 远景（不推荐）

**问题**：
- 横向空间不足
- 人物太小，看不清
- 环境信息有限

**替代方案**：
- 改用纵向远景（高楼、楼梯）
- 改用全景
- 用字幕/对白交代环境

#### 全景（谨慎使用）

**优势**：
- 可以展现人物全身
- 竖屏纵向空间大，效果尚可

**注意**：
- 避免过多使用
- 背景不要太复杂
- 人物要突出

#### 中景（大力推荐）⭐⭐⭐⭐⭐

**优势**：
- 最适合竖屏
- 能展现表情和动作
- 对话场景首选

**应用**：
- 日常对话
- 动作展示
- 互动场景

#### 近景（大力推荐）⭐⭐⭐⭐⭐

**优势**：
- 突出面部表情
- 充分利用竖屏空间
- 情绪表达首选

**应用**：
- 情绪场景
- 金句对白
- 重要时刻

#### 特写（大力推荐）⭐⭐⭐⭐⭐

**优势**：
- 视觉冲击力强
- 细节清晰
- 爽点时刻首选

**应用**：
- 眼神特写
- 物品特写
- 爽点时刻

## 竖屏运镜技巧

### 推荐运镜方式

| 运镜 | 竖屏适配度 | 占比建议 |
|------|-----------|---------|
| **固定** | ⭐⭐⭐⭐⭐ | 50-60% |
| **推镜** | ⭐⭐⭐⭐⭐ | 10-15% |
| **拉镜** | ⭐⭐⭐⭐ | 5-10% |
| **跟镜** | ⭐⭐⭐⭐⭐ | 10-15% |
| **升降** | ⭐⭐⭐⭐ | 2-5% |
| **摇镜** | ⭐⭐⭐ | 5-10% |
| **移镜** | ⭐⭐⭐ | 3-5% |

### 纵向运镜（推荐）

#### 1. 纵向推镜 ⭐⭐⭐⭐⭐

**方向**：从远到近，从上到下

**效果**：突出细节，增强情绪

**示例**：
```
开始：人物全身（全景）
      ↓ 推进
中间：人物上半身（中景）
      ↓ 继续推进
结束：人物面部（近景/特写）
```

**应用**：
- 情绪递进场景
- 重要时刻的强调
- 爽点前的铺垫

#### 2. 纵向拉镜 ⭐⭐⭐⭐

**方向**：从近到远，从下到上

**效果**：展现环境，制造疏离感

**示例**：
```
开始：人物面部特写
      ↓ 拉远
中间：人物上半身
      ↓ 继续拉远
结束：人物全身+环境
```

**应用**：
- 揭示环境
- 制造孤独感
- 场景结束

#### 3. 纵向升降 ⭐⭐⭐⭐

**方向**：上升或下降

**效果**：展现高度，制造视角变化

**示例A（上升）**：
```
开始：地面/脚部
      ↓ 上升
中间：身体
      ↓ 继续上升
结束：面部/头顶
```

**示例B（下降）**：
```
开始：楼顶/天空
      ↓ 下降
中间：楼层
      ↓ 继续下降
结束：地面/人物
```

**应用**：
- 展现人物形象（从脚到头）
- 展现建筑（从下到上）
- 制造视角变化

#### 4. 纵向跟镜 ⭐⭐⭐⭐⭐

**方向**：前后跟随人物

**效果**：增强代入感，动态感

**示例**：
```
镜头跟随人物从后方
人物向前走，镜头跟随
```

**应用**：
- 人物行走场景
- 追逐场景
- 增强代入感

### 横向运镜（谨慎使用）

#### 5. 横向摇镜 ⭐⭐⭐

**限制**：横向空间小，摇动范围受限

**替代方案**：
- 改用多个固定镜头切换
- 改用纵向推拉
- 改用跟镜

**适用场景**：
- 必须展现横向环境时
- 两个横向距离较近的主体

#### 6. 横向移镜 ⭐⭐⭐

**限制**：横向空间小，移动效果不明显

**替代方案**：
- 改用跟镜（前后跟随）
- 改用固定镜头

**适用场景**：
- 展现横向短距离的空间关系

## 竖屏多人场景处理

### 问题

**横屏多人场景**：可以横向排列
```
横屏：[人A] [人B] [人C] ← 横向排列，画面舒适
```

**竖屏多人场景**：横向空间不足
```
竖屏：[人A][人B][人C] ← 挤在一起，不舒适
```

### 解决方案

#### 方案1：前后景排列

**纵向排列**，利用前后景深
```
竖屏：
  近景：[人A]
  中景：[人B]
  远景：[人C]
```

**优势**：
- 充分利用纵向空间
- 有层次感
- 每个人物清晰可见

#### 方案2：切镜头

**不要一个镜头拍多人，改用多个镜头切换**
```
镜头1：人A说话（近景）
镜头2：人B反应（近景）
镜头3：人C插话（近景）
```

**优势**：
- 每个人物都能特写
- 表情清晰
- 符合竖屏特点

#### 方案3：纵向排列

**多人纵向排列**，如坐在楼梯上
```
竖屏：
  上方：[人A]
  中间：[人B]
  下方：[人C]
```

**优势**：
- 利用纵向空间
- 有层次感
- 构图有趣

## 竖屏场景选择

### 适合竖屏的场景

#### 1. 纵向空间场景

**示例**：
- 楼梯
- 电梯
- 高楼
- 瀑布
- 门框
- 走廊

**优势**：充分利用竖屏的纵向空间

#### 2. 单人场景

**示例**：
- 单人对话
- 独白
- 单人动作

**优势**：人物突出，空间利用充分

#### 3. 前后景场景

**示例**：
- 追逐场景
- 行走场景
- 前后对话

**优势**：利用纵深而非横向

### 不适合竖屏的场景（需要调整）

#### 1. 横向宽广场景

**问题**：横向空间不足，展现不全

**替代方案**：
- 改用多个镜头展现
- 改用纵向场景
- 用对白/字幕交代

#### 2. 多人横向排列场景

**问题**：人物挤在一起，不舒适

**替代方案**：
- 改用前后景排列
- 改用切镜头
- 改用纵向排列

#### 3. 横向动作场景

**问题**：横向运动空间不足

**替代方案**：
- 改用纵向运动（向前/向后）
- 改用跟镜
- 分段拍摄

## 竖屏拍摄技巧

### 技巧1：充分利用纵向空间

**方法**：
- 多用从头到脚的全身镜头
- 多用楼梯、门框等纵向元素
- 多用纵向推拉镜头

### 技巧2：突出主体

**方法**：
- 背景虚化，突出人物
- 中景和近景为主
- 避免背景过于复杂

### 技巧3：多用特写

**方法**：
- 面部特写
- 眼神特写
- 物品特写

**效果**：
- 视觉冲击力强
- 充分利用竖屏
- 情绪表达清晰

### 技巧4：前后景深

**方法**：
- 近景主体 + 远景背景
- 多人场景前后排列
- 制造空间层次感

### 技巧5：切镜头代替摇镜

**方法**：
- 不用横向摇镜展现多个主体
- 改用多个固定镜头切换
- 节奏更快，信息更清晰

## 竖屏后期处理

### 1. 剪辑节奏

**竖屏节奏要更快**：
- 镜头时长：1-3秒（比横屏更短）
- 快速切换，保持节奏
- 避免拖沓

### 2. 字幕处理

**竖屏字幕位置**：
- 上半部分：环境信息、地点
- 中间：对白字幕
- 下半部分：补充信息、提示

**字幕大小**：
- 比横屏更大（手机屏幕小）
- 清晰易读
- 不遮挡主体

### 3. 特效处理

**适合竖屏的特效**：
- 文字动画（从上到下）
- 转场特效（纵向滑动）
- 画面分割（上下分屏）

**不适合竖屏的特效**：
- 横向滑动转场
- 左右分屏
- 横向文字滚动

## 检查清单

在完成竖屏分镜设计后，使用此清单检查：

### 构图检查

- [ ] 充分利用纵向空间？
- [ ] 主体突出，不被背景干扰？
- [ ] 多人场景使用前后景或切镜头？

### 景别检查

- [ ] 中景+近景+特写占70%以上？
- [ ] 远景和全景谨慎使用？
- [ ] 景别分布合理？

### 运镜检查

- [ ] 多用纵向运镜（推拉跟升降）？
- [ ] 少用横向运镜（摇移）？
- [ ] 运镜流畅自然？

### 场景检查

- [ ] 场景适合竖屏拍摄？
- [ ] 多人场景有合理处理方案？
- [ ] 横向宽广场景有替代方案？
