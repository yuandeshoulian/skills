# 短剧剧本核心规则

本文档定义短剧创作的核心约束和规则，确保剧本「合理且爽」。

---

## 金手指限制规则

### 核心原则

**主角的优势必须有合理来源，不能依赖无脑金手指**

| ❌ 禁止 | ✅ 允许 |
|---------|---------|
| 主角突然获得系统/金手指 | 主角通过前世记忆/经验获得信息优势 |
| 主角无脑碾压所有反派 | 主角需要智谋、布局、付出代价才能赢 |
| 反派集体智商下线 | 反派也有智商，主角需要更高一筹 |
| 主角随意开挂获得资源 | 主角通过合理方式（投资、交易、合作）获得资源 |
| 所有配角都爱慕主角 | 主角需要展现魅力/能力才能获得认可 |
| 主角遇到危险必有贵人相救 | 主角需要提前布局或自己解决危机 |
| 主角一出手就是绝世武功/商业天才 | 主角需要有合理的技能来源（学习/前世经验/天赋+努力） |

### 详细说明

#### 1. 禁止突然出现的系统/金手指

**❌ 错误示例**：
```
主角突然获得「商业之神系统」，只要完成任务就能获得技能点，瞬间成为商业天才。
```

**✅ 正确示例**：
```
主角是重生者，前世在商界摸爬滚打30年，虽然最终失败，但积累了丰富的经验和教训。
这一世利用前世记忆和经验，提前布局，避开陷阱，抓住机遇。
```

#### 2. 禁止主角无脑碾压

**❌ 错误示例**：
```
反派设局陷害主角，主角随手一招就破解，反派束手无策。
```

**✅ 正确示例**：
```
反派设局陷害主角，主角一开始也陷入困境，但通过仔细观察发现破绽，
然后暗中收集证据，联合盟友，经过一番斗智斗勇，最终将计就计，反将反派一军。
```

#### 3. 禁止反派集体降智

**❌ 错误示例**：
```
反派明明掌握大量资源和人脉，却在关键时刻犯下低级错误，被主角轻易击败。
```

**✅ 正确示例**：
```
反派同样聪明且谨慎，有自己的智囊团和布局。
主角需要更胜一筹的策略，或者利用反派不知道的信息差，才能取胜。
反派的失败是因为主角更聪明，而不是反派太蠢。
```

#### 4. 禁止随意获得资源

**❌ 错误示例**：
```
主角在路上遇到一个老人，老人看主角顺眼，直接赠送一栋价值数亿的大楼。
```

**✅ 正确示例**：
```
主角发现一个被低估的商业项目，通过专业分析判断其潜力，说服投资人合作。
项目成功后，主角获得应得的回报。整个过程有逻辑、有因果。
```

#### 5. 禁止所有人都爱慕主角

**❌ 错误示例**：
```
主角走到哪里，所有人都被主角的气质折服，纷纷投靠。
```

**✅ 正确示例**：
```
主角需要展现实力、魅力、或帮助别人，才能逐步获得认可。
有些人欣赏主角，有些人质疑主角，有些人嫉妒主角。人物反应要多样化、真实化。
```

## 智慧型爽点设计原则

### 五种智慧型爽点

#### 1. 提前布局型爽点

**定义**：主角早已埋下伏笔，在关键时刻揭晓

**示例**：
```
第15集：反派以为掌控了主角的公司，准备吞并。
第16集：主角揭晓，其实早在三个月前就暗中收购了反派的核心供应商，
        反派的公司反而陷入困境。反派震惊："你什么时候布的局？！"
        主角淡定："从你露出獠牙的那一刻。"
```

**爽点来源**：
- 观众会惊叹：原来前面的细节是伏笔！
- 反派的震惊就是观众的爽感
- 展现主角的深谋远虑

#### 2. 信息差爽点

**定义**：主角知道反派不知道的信息

**示例**：
```
主角是重生者，知道三个月后某家公司会宣布重大技术突破，股价暴涨。
反派笑话主角投资这家"濒临破产"的公司，认为主角是傻子。
三个月后，公司宣布突破，股价飙升，反派傻眼。
```

**爽点来源**：
- 观众和主角站在同一视角，知道真相
- 看着反派自以为是，观众爽感十足
- 信息差必须合理：重生/穿越/内部消息/专业判断

#### 3. 智谋碾压爽点

**定义**：主角用策略而非武力/金钱碾压

**示例**：
```
反派设局让主角在商业会议上出丑。
主角察觉陷阱，将计就计，在会议上故意"出丑"，引反派上钩。
反派得意洋洋，以为计划成功，却不知主角已暗中录音录像。
关键时刻主角公布证据，反派身败名裂。
```

**爽点来源**：
- 主角不是靠金手指，而是靠智慧
- 反派搬起石头砸自己的脚
- 观众欣赏主角的智谋

#### 4. 成长型爽点

**定义**：主角通过学习/积累实力后爆发

**示例**：
```
第1-20集：主角被轻视，但默默学习、积累、建立人脉。
第21集：在关键比赛/会议/谈判中，主角展现出惊人的实力和底蕴，
        震惊所有曾经轻视他的人。"他什么时候变得这么强？"
```

**爽点来源**：
- 前期积累+后期爆发=爽感
- 让观众看到主角的努力有回报
- 打脸曾经轻视主角的人

#### 5. 合理机遇爽点

**定义**：机遇的出现要有因果逻辑

**❌ 错误示例**：
```
主角走在路上，突然捡到一本绝世秘籍。
```

**✅ 正确示例**：
```
主角因为研究某个冷门领域，在学术会议上遇到该领域的权威教授。
教授欣赏主角的钻研精神，愿意指点主角，并引荐资源。
主角获得了机遇，但这个机遇有因果：因为主角的努力和专业性。
```

**爽点来源**：
- 机遇不是凭空而来，而是主角努力的结果
- 观众会认为"主角值得这个机遇"
- 避免"主角运气太好"的套路感

## 对白规则

### 核心原则

**短视频节奏快，对白必须简洁有力**

### 规则清单

| 规则 | 说明 | 示例 |
|------|------|------|
| **字数限制** | 每句对白不超过20个字 | ✅「你以为我会输？」<br>❌「你以为我会在这种情况下输给你吗？」|
| **禁止AI味词汇** | 避免书面语、古风词汇 | ❌「不过如此」「蝼蚁」「尔等」「本座」<br>✅「就这？」「你们这些人」「我」 |
| **多用短句** | 短句比长句更有力 | ✅「我不同意。」<br>❌「对于这件事情我不能够同意。」 |
| **多用反问** | 反问增强语气 | ✅「你觉得我会怕吗？」<br>❌「我不会怕的。」 |
| **多用感叹** | 感叹表达情绪 | ✅「太好了！」<br>❌「这真是一个好消息。」 |
| **每集1句金句** | 可传播的台词 | 「三年之期已到，龙王归来」<br>「你刚才说谁是废物？」 |

### 金句类型

#### 1. 打脸型金句

适用场景：主角反击时

**示例**：
- 「你刚才说谁是废物？」
- 「就这？」
- 「还有谁？」
- 「现在，该我了」

#### 2. 反转型金句

适用场景：剧情反转时

**示例**：
- 「游戏，才刚刚开始」
- 「你以为这就结束了？」
- 「这才是真正的开始」
- 「我等的就是这一刻」

#### 3. 揭秘型金句

适用场景：揭露真相时

**示例**：
- 「你以为我不知道？」
- 「该揭晓答案了」
- 「让我告诉你真相」
- 「你想知道为什么吗？」

#### 4. 霸气型金句

适用场景：主角展现实力时

**示例**：
- 「我说的，谁赞成，谁反对？」
- 「在我面前，你不够格」
- 「这个世界，我说了算」
- 「我让你三招」

**注意**：霸气型金句要结合剧情，不能生硬。主角要有实力和底气。

### 禁止的对白模式

#### 1. 长篇大论解释剧情

**❌ 错误示例**：
```
「事情是这样的，三年前我遭遇了家族的背叛，被赶出家门，
流落街头，但我通过自己的努力，一步步积累实力，
现在我回来了，要夺回属于我的一切。」
```

**✅ 正确示例**：
```
「三年了，我回来了。」
「你们欠我的，今天都要还。」
```

#### 2. 过度的心理独白

**❌ 错误示例**：
```
（心理独白）：他真的以为我不知道他的计划吗？太天真了。
我早就设好了陷阱，等他自投罗网。
```

**✅ 正确示例**：
```
（心理独白）：来吧，自投罗网。
```

#### 3. 重复说明已知信息

**❌ 错误示例**：
```
「你不是说你是商业天才吗？你不是说你能赚很多钱吗？
现在怎么样？你失败了对不对？」
```

**✅ 正确示例**：
```
「天才？就这？」
```

#### 4. AI味重的书面语

**❌ 禁用词汇**：
- 不过如此
- 蝼蚁、尔等、本座
- 岂不美哉
- 甚好、极佳
- 如你所愿
- 恕不奉陪

**✅ 替代方案**：
- 就这？
- 你们这些人、你、我
- 不是挺好
- 很好、不错
- 随你便
- 我不奉陪了

## 节奏规则

### 核心原则

**每集必须有明确的钩子、事件、悬念**

### 每集标准结构

```
┌─────────────────────────────────────┐
│ 钩子（前10秒）                       │
│ - 冲突/疑问/悬念                     │
│ - 吸引观众注意力                     │
├─────────────────────────────────────┤
│ 核心事件（中间部分）                 │
│ - 推进剧情的关键事件                 │
│ - 对白、动作、冲突                   │
├─────────────────────────────────────┤
│ 悬念/爽点（结尾）                    │
│ - 下集预告                           │
│ - 爽点（打脸/反转）                  │
└─────────────────────────────────────┘
```

### 钩子设计

**前10秒必须抓住观众**

**好的钩子类型**：
1. **冲突钩子**：「你敢打我？」
2. **悬念钩子**：「他来了...」
3. **反转钩子**：「这不可能！」
4. **威胁钩子**：「今天，你死定了」

**示例**：
```
第1集钩子：
画面：豪华酒店，主角被保安拦在门外。
保安：「穷鬼，这里不是你能来的地方。」
主角淡定一笑：「是吗？」
[钩子设定完成，观众想知道：主角会怎么做？]
```

### 整体节奏规划

| 阶段 | 集数范围 | 节奏要求 | 爽点密度 |
|------|---------|---------|---------|
| **开局** | 第1-3集 | 必须有强钩子 | 至少1个爽点 |
| **发展** | 第4-20集 | 建立冲突，小爽点密集 | 每3-5集1个小爽点 |
| **危机** | 第21-40集 | 冲突升级，中期大危机 | 每5-7集1个中爽点 |
| **高潮** | 第41-60集 | 最终对决，大爽点密集 | 每3-5集1个大爽点 |
| **结局** | 第61-80集 | 收尾，完美结局 | 最后2-3集连续爽点 |

### 必须遵守的节奏约束

#### 1. 前3集必须有强钩子

**理由**：短视频平台，观众没耐心，前3集不吸引人就会弃剧。

**强钩子示例**：
- 第1集：主角遭遇重大羞辱/打击
- 第2集：主角展现惊人的能力/身份
- 第3集：主角第一次小爽点/打脸

#### 2. 每10-15集必须有大爽点/反转

**理由**：避免观众疲劳，保持新鲜感。

**大爽点示例**：
- 主角身份揭晓
- 反派遭遇重大失败
- 主角完成重要目标
- 重大剧情反转

#### 3. 避免连续3集没有明显情节推进

**理由**：观众会觉得拖沓，失去耐心。

**检查方法**：
- 读任意连续3集，是否有明显的情节推进？
- 是否有新的冲突/爽点/反转？
- 如果没有，需要调整

## 人物行为合理性规则

### 主角行为约束

1. **动机必须清晰**：主角的每个重要决定都要有明确的动机
2. **行为必须符合设定**：商业天才不能突然变成武林高手（除非有合理解释）
3. **必须有成长空间**：主角不能一开始就完美无缺
4. **必须付出代价**：主角的成功不能毫无代价

### 反派行为约束

1. **智商在线**：反派不能因为剧情需要就犯低级错误
2. **动机合理**：反派的恶要有利益驱动或心理原因
3. **实力匹配**：反派不能太弱，要能与主角形成对抗
4. **失败有原因**：反派失败是因为主角更强，而不是反派太蠢

### 配角行为约束

1. **功能性明确**：每个配角都有存在意义
2. **避免工具人**：配角也要有基本人格和动机
3. **关系合理**：配角与主角的关系要有建立过程

## 剧情逻辑规则

### 因果关系

**每个重要事件都要有因果关系**

**❌ 错误示例**：
```
主角突然获得一大笔钱，没有任何解释。
```

**✅ 正确示例**：
```
主角通过前世记忆，提前投资了一个即将暴涨的项目，获得回报。
```

### 伏笔回收

**埋下的伏笔必须回收**

**示例**：
- 第5集：主角神秘地说「我还有一张底牌」
- 第15集：必须揭晓这张底牌是什么

### 时间线一致

**剧情时间线要清晰、一致**

**检查要点**：
- 主角的年龄、身份、背景前后一致
- 事件发生的时间顺序合理
- 重生/穿越的时间点明确

## 检查清单

在输出剧本前，使用此清单检查：

### 金手指检查

- [ ] 主角的优势有合理来源？
- [ ] 反派智商在线？
- [ ] 主角获得资源有合理途径？
- [ ] 没有过度依赖系统/金手指？

### 爽点检查

- [ ] 爽点基于智慧/策略/努力？
- [ ] 爽点密度合理（每3-5集1个小爽点）？
- [ ] 每10-15集有1个大爽点/反转？

### 对白检查

- [ ] 每句对白≤20字？
- [ ] 没有AI味词汇？
- [ ] 每集至少1句金句？

### 节奏检查

- [ ] 每集有钩子+事件+悬念？
- [ ] 前3集有强钩子？
- [ ] 无连续3集平淡期？

### 逻辑检查

- [ ] 人物行为合理？
- [ ] 因果关系清晰？
- [ ] 伏笔有回收？
- [ ] 时间线一致？

---

**遵守这些规则，确保剧本「合理且爽」！**
