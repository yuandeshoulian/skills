# 镜头语言基础

本文档介绍分镜脚本设计的基础知识，包括景别、角度、运镜等核心概念。

---

## 景别类型

### 什么是景别？

**景别**是指摄影机与被摄对象的距离所形成的画面范围。

### 五大景别

#### 1. 远景（Long Shot / LS）

**定义**：展现广阔环境和大场景

**画面范围**：包含完整场景，人物很小或看不清

**用途**：
- 交代故事发生的地点和环境
- 展现场景的规模和氛围
- 场景开始的建立镜头

**竖屏适配**：⭐⭐（2星，横向空间不足，较少使用）

**示例**：
```
城市街道远景，高楼林立，车水马龙。
林宇的身影在画面底部，显得渺小。
```

**使用建议**：
- 竖屏中谨慎使用，横向空间有限
- 可改用竖向远景（如高楼从下往上）
- 必要时使用，但不宜过多

---

#### 2. 全景（Full Shot / FS）

**定义**：人物全身+部分周围环境

**画面范围**：从头到脚，能看清人物动作

**用途**：
- 展示人物的整体形象和动作
- 交代人物与环境的关系
- 人物进出场景

**竖屏适配**：⭐⭐⭐（3星，尚可，适合纵向构图）

**示例**：
```
林宇站在酒店门口，从头到脚完整入镜。
背景是酒店大门和部分大堂。
```

**使用建议**：
- 竖屏中较为适合，能展现人物全身
- 适合人物站立、走动的镜头
- 可突出人物的服装和姿态

---

#### 3. 中景（Medium Shot / MS）

**定义**：人物腰部以上

**画面范围**：膝盖或腰部以上到头顶

**用途**：
- 展示人物的手势和动作
- 人物对话和互动
- 最常用的景别之一

**竖屏适配**：⭐⭐⭐⭐⭐（5星，非常适合）

**示例**：
```
林宇腰部以上入镜，伸手指向前方。
能看清他的表情和手势。
```

**使用建议**：
- 竖屏中最常用的景别（占40-50%）
- 适合对话、动作、互动场景
- 能兼顾表情和动作

---

#### 4. 近景（Close-up / CU）

**定义**：人物胸部以上

**画面范围**：肩部或胸部以上到头顶

**用途**：
- 展示人物面部表情
- 强调情绪和心理状态
- 重要对白的镜头

**竖屏适配**：⭐⭐⭐⭐⭐（5星，非常适合）

**示例**：
```
林宇胸部以上入镜，面部表情清晰可见。
眼神坚定，嘴角微微上扬。
```

**使用建议**：
- 竖屏中非常常用（占30-40%）
- 适合情绪表达、金句对白
- 能让观众看清细微表情

---

#### 5. 特写（Extreme Close-up / ECU）

**定义**：面部或物品的细节

**画面范围**：只有面部或物品的局部

**用途**：
- 强调关键细节（眼神、物品）
- 制造悬念和紧张感
- 爽点时刻的强调

**竖屏适配**：⭐⭐⭐⭐⭐（5星，非常适合）

**示例**：
```
林宇的眼睛特写，瞳孔中倒映着前方的人影。
眼神冷冽，杀气毕露。
```

**使用建议**：
- 竖屏中效果极佳（占10-20%）
- 用于关键时刻，不宜过多
- 能制造强烈的视觉冲击

---

### 景别组合原则

#### 原则1：从远到近，从近到远

**示例**：
```
S1-1: 全景 - 林宇走进酒店
S1-2: 中景 - 林宇停下脚步
S1-3: 近景 - 林宇的表情
S1-4: 特写 - 林宇的眼神
```

**作用**：逐步引导观众注意力，从环境到人物到情绪。

#### 原则2：对话场景交替使用

**示例**：
```
S1-1: 中景 - 保安说话
S1-2: 近景 - 林宇回应
S1-3: 中景 - 保安反应
S1-4: 近景 - 林宇继续说
```

**作用**：交替展示对话双方，保持节奏。

#### 原则3：爽点时刻用特写

**示例**：
```
S1-1: 中景 - 反派得意洋洋
S1-2: 近景 - 主角淡定一笑
S1-3: 特写 - 主角的眼神（霸气）
S1-4: 中景 - 反派震惊的表情
```

**作用**：用特写强调爽点时刻，增强冲击力。

## 拍摄角度

### 角度类型

#### 1. 平视（Eye Level）

**定义**：镜头与被摄对象保持水平

**效果**：中性、客观、真实

**用途**：
- 日常对话
- 客观叙事
- 最常用的角度（占70-80%）

**示例**：
```
镜头与林宇的眼睛保持同一水平。
平视拍摄林宇与保安的对话。
```

---

#### 2. 仰视（Low Angle）

**定义**：镜头从下往上拍摄

**效果**：展现角色强大、威严、压迫感

**用途**：
- 展现角色的强大或地位
- 制造崇敬感或压迫感
- 爽点时刻展现主角的霸气

**示例**：
```
镜头从下往上拍摄林宇。
林宇站立，居高临下看着跪地的反派。
显得威严强大。
```

**使用建议**：
- 用于主角展现实力的时刻
- 不宜过多使用（占5-10%）

---

#### 3. 俯视（High Angle）

**定义**：镜头从上往下拍摄

**效果**：展现角色弱小、孤独、脆弱

**用途**：
- 展现角色的困境或孤独
- 制造渺小感或脆弱感
- 反派失败时的镜头

**示例**：
```
镜头从上往下拍摄失败的反派。
反派跪地，显得渺小无助。
```

**使用建议**：
- 用于展现角色困境或失败
- 占5-10%

---

#### 4. 侧面（Profile）

**定义**：从侧面拍摄人物

**效果**：展现轮廓、距离感、思考状态

**用途**：
- 展现角色的轮廓和侧脸
- 角色思考或观察时
- 制造距离感或冷静感

**示例**：
```
镜头从侧面拍摄林宇。
林宇站在窗前，侧脸轮廓分明，若有所思。
```

**使用建议**：
- 用于安静思考的时刻
- 占5-10%

---

#### 5. 荷兰角（Dutch Angle）

**定义**：镜头倾斜拍摄

**效果**：失衡感、不安感、紧张感

**用途**：
- 制造紧张或不安的氛围
- 展现角色内心的混乱
- 悬疑或惊悚场景

**示例**：
```
镜头倾斜15度拍摄。
林宇站在废弃工厂，画面倾斜，制造不安感。
```

**使用建议**：
- 谨慎使用，过多会让观众不适
- 仅用于特殊场景（占1-2%）

---

## 运镜方式

### 静态镜头

#### 1. 固定镜头（Static Shot）

**定义**：机位完全不动

**效果**：稳定、正式、客观

**用途**：
- 对话场景
- 需要稳定画面的时刻
- 最常用的运镜（占50-60%）

**竖屏适配**：⭐⭐⭐⭐⭐（5星）

**示例**：
```
镜头固定，林宇与保安对话。
机位不动，只记录对话内容。
```

---

### 动态镜头

#### 2. 推镜（Push In / Dolly In）

**定义**：镜头向前推进

**效果**：突出细节、增强情绪、制造紧张感

**用途**：
- 从环境推到人物
- 从中景推到特写
- 增强情绪表达

**竖屏适配**：⭐⭐⭐⭐⭐（5星，非常适合）

**示例**：
```
镜头从中景开始，缓慢推进到林宇的近景特写。
林宇的表情从平静到冷冽，情绪逐步增强。
```

**使用建议**：
- 竖屏中非常适合纵向推进
- 用于情绪递进或突出细节
- 占10-15%

---

#### 3. 拉镜（Pull Out / Dolly Out）

**定义**：镜头向后拉远

**效果**：展现环境、制造疏离感、揭示全貌

**用途**：
- 从特写拉到全景
- 揭示隐藏的信息
- 制造孤独或疏离感

**竖屏适配**：⭐⭐⭐⭐（4星）

**示例**：
```
镜头从林宇的特写开始，缓慢拉远。
逐渐展现出林宇站在空旷的大厅中，显得孤独。
```

**使用建议**：
- 用于揭示环境或制造疏离感
- 占5-10%

---

#### 4. 摇镜（Pan）

**定义**：镜头左右摇动

**效果**：扫视环境、跟随动作

**用途**：
- 扫视场景
- 跟随人物或物体横向移动

**竖屏适配**：⭐⭐⭐（3星，横向受限）

**示例**：
```
镜头从林宇摇到远处走来的前女友。
横向扫视，展示两人的位置关系。
```

**使用建议**：
- 竖屏中横向空间有限，谨慎使用
- 可改用纵向升降
- 占5-10%

---

#### 5. 移镜（Tracking / Trucking）

**定义**：镜头横向移动

**效果**：展现空间、跟随移动

**用途**：
- 跟随人物横向行走
- 展现空间的连续性

**竖屏适配**：⭐⭐⭐（3星，横向受限）

**示例**：
```
镜头跟随林宇横向行走。
从左向右移动，展现走廊的空间。
```

**使用建议**：
- 竖屏中横向移动受限
- 可改用跟镜（前后跟随）
- 占3-5%

---

#### 6. 跟镜（Follow Shot）

**定义**：镜头跟随人物移动

**效果**：增强代入感、动态感

**用途**：
- 跟随人物行走
- 制造紧张或追逐感
- 增强观众代入感

**竖屏适配**：⭐⭐⭐⭐⭐（5星，非常适合）

**示例**：
```
镜头跟随林宇从后方。
林宇大步走向酒店大门，镜头跟随其后。
```

**使用建议**：
- 竖屏中非常适合纵向跟随
- 用于人物移动或动作场景
- 占10-15%

---

#### 7. 升降镜头（Crane / Pedestal）

**定义**：镜头上下运动

**效果**：展现高度、制造视角变化

**用途**：
- 从地面升到高处
- 从高处降到地面
- 展现场景的纵深

**竖屏适配**：⭐⭐⭐⭐（4星）

**示例**：
```
镜头从地面缓慢上升。
从林宇的脚部升到面部，展现其完整形象。
```

**使用建议**：
- 竖屏中纵向运动效果好
- 用于特殊时刻，不宜过多
- 占2-5%

## 镜头衔接原则

### 原则1：轴线法则（180度法则）

**定义**：保持镜头在同一侧拍摄，避免跳轴

**示例**：
```
林宇（左）对话 保安（右）
S1: 从林宇这侧拍摄，林宇在左，保安在右
S2: 从保安这侧拍摄，保安在左，林宇在右

❌ 错误：两个镜头都从同一侧拍摄，导致两人位置混乱
✅ 正确：交替从两侧拍摄，保持位置关系
```

### 原则2：动接动，静接静

**定义**：动态镜头接动态镜头，静态镜头接静态镜头

**示例**：
```
✅ 正确：
S1: 林宇快速奔跑（动）
S2: 镜头跟随林宇（动）

❌ 错误：
S1: 林宇快速奔跑（动）
S2: 固定镜头展示环境（静）← 节奏断裂
```

### 原则3：景别逐级变化

**定义**：景别不要跳跃太大

**示例**：
```
✅ 正确：全景 → 中景 → 近景 → 特写（逐级）
❌ 错误：全景 → 特写（跳跃太大）

例外：刻意制造视觉冲击时可跳跃
```

## 镜头时长建议

### 一般原则

| 镜头类型 | 时长 | 说明 |
|---------|------|------|
| **固定对话** | 2-4秒 | 看清内容即可 |
| **推拉镜头** | 3-5秒 | 需要时间展现运动 |
| **特写镜头** | 2-3秒 | 强调细节，不宜过长 |
| **动作镜头** | 1-2秒 | 快节奏剪辑 |
| **情绪镜头** | 3-5秒 | 给观众时间体会情绪 |

### 短视频特殊要求

**竖屏短视频节奏更快，镜头时长要更短**

- 平均2-3秒/镜头
- 快节奏场景：1-2秒/镜头
- 爽点场景：可适当延长到4-5秒

## 检查清单

在完成分镜设计后，使用此清单检查：

### 景别检查

- [ ] 中景+近景+特写占70%以上？
- [ ] 远景和全景谨慎使用？
- [ ] 景别有变化，不单调？

### 角度检查

- [ ] 平视占70-80%？
- [ ] 特殊角度用于特殊时刻？
- [ ] 仰视用于展现强大？
- [ ] 俯视用于展现弱小？

### 运镜检查

- [ ] 固定镜头占50-60%？
- [ ] 推拉跟镜适度使用？
- [ ] 横向摇移谨慎使用（竖屏受限）？
- [ ] 运镜服务于情节和情绪？

### 衔接检查

- [ ] 遵守轴线法则？
- [ ] 动接动，静接静？
- [ ] 景别逐级变化？

### 时长检查

- [ ] 平均镜头时长2-3秒？
- [ ] 镜头时长服务于节奏？
- [ ] 无过长或过短的镜头？
